## 📋 Descripción

Implementación y análisis comparativo de cuatro algoritmos de búsqueda (**BFS, DFS, UCS y A\***) aplicados a tres problemas clásicos de Inteligencia Artificial:

1. **8-Puzzle** — búsqueda en espacio de estados con costo uniforme.
2. **Mapa de Rumania** — búsqueda en grafo con costos no uniformes.
3. **Knapsack 0/1** (opcional) — optimización combinatoria reformulada como búsqueda.

El objetivo no es determinar "el mejor algoritmo", sino comprender cómo la representación del problema, los costos y la información heurística determinan el comportamiento observado.

## Instrucciones de ejecución

1. Abrir `busqueda_informada.ipynb` en Google Colab.
2. Ejecutar **Runtime → Run all**.
3. Esperar a que termine (1-3 min).
4. Se generan automáticamente `resultados.xlsx` y `evidencias_laboratorio.zip`.
